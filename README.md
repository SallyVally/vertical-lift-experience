# Лифт Монтаж Сервис

Интерактивная концепция сайта о монтаже, обслуживании и модернизации лифтов.

Статическая версия для GitHub Pages: 3D-кабина, загрузка с открытием дверей, анимации текста и прокрутка страницы.

Данные компании перенесены из предоставленного буклета. Форма готовит текст обращения и письмо в почтовом приложении; отправку выполняет посетитель. Доступны три цветовых оформления.

## Локальный просмотр

Запустите любой статический HTTP-сервер из корня репозитория, например `python -m http.server 3000`.

## Публикация

GitHub Pages: ветка `main`, корень `/`. Все пути к ресурсам относительные.

Сведения о сторонних материалах — в [ASSET-SOURCES.md](ASSET-SOURCES.md).
